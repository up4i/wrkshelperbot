## Task 8: Bet Inputs Accept 1k / 1m / 1b Shorthand

**Files:** `miniapp/static/index.html`

**Goal:** Player types `1k` → bet input shows `1,000`. Typing `2.5m` → shows `2,500,000`. Works on all `.bet-input` fields including BJ chip input if any.

- [ ] **Replace `_formatBetInput` with shorthand-aware version:**

Find:
```javascript
function _formatBetInput(el) {
  const raw = el.value.replace(/,/g, '');
  if (!/^\d*$/.test(raw)) { el.value = el.value.slice(0, -1); return; }
  if (raw) el.value = Number(raw).toLocaleString('en-US');

```
Replace with:
```javascript
function _formatBetInput(el) {
  const raw = el.value.replace(/,/g, '').trim().toLowerCase();
  const m = raw.match(/^(\d+(?:\.\d+)?)\s*([kmb])?$/);
  if (!m) { el.value = el.value.slice(0, -1); return; }
  const num = parseFloat(m[1]);
  const mult = m[2] === 'b' ? 1_000_000_000 : m[2] === 'm' ? 1_000_000 : m[2] === 'k' ? 1_000 : 1;
  const val = Math.floor(num * mult);
  if (isNaN(val) || val < 0) { el.value = el.value.slice(0, -1); return; }
  // Only format to comma if user ended with Enter or Tab, not while still typing a suffix
  if (m[2] || (!m[2] && !raw.match(/[kmb]$/))) {
    el.value = val.toLocaleString('en-US');
  }
}
```
